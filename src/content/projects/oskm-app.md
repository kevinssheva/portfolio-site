A web application developed to support student orientation activities, combining real-time communication, event management, and interactive features.

Key features include:

- **Real-time chat:** Anonymous messaging with profile reveal functionality, built using Go, Redis, and WebSocket.
- **Topic matching:** Chat matching and queue management based on participants' interests.
- **Gamification:** Quest and leaderboard systems designed to encourage participant engagement.
- **Event management:** Features supporting orientation activities and participant interactions.

**Tech Stack:** Go, PostgreSQL, Next.js, Tailwind CSS, Redis, WebSocket.
