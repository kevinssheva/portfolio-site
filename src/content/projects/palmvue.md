PalmVue is an ERP system designed to support palm-seed tracking and operational workflows.

Key features include:

- **Schema-driven workflows:** Flexible data structures that support configurable business processes and dynamic data inputs.
- **Conversational analytics:** An AI-powered interface that translates natural-language questions into SQL queries to retrieve operational data.
- **Offline synchronization:** Scheduler-based synchronization that enables mobile users to work in environments with unstable network connectivity.

**Tech Stack:** Go, Next.js, React Native, PostgreSQL, Redis, OpenAI API.
