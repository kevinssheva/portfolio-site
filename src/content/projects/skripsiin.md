Skripsiin is a web application that explores the use of LLM-powered agents to assist with academic writing workflows.

Key features include:

- **LLM-powered agents:** Generate and revise thesis chapters based on user input.
- **Real-time streaming:** Stream generated content using Server-Sent Events (SSE), allowing users to see results as they are produced.
- **Progress tracking:** Provide live updates throughout the content generation process.

**Tech Stack:** FastAPI, Next.js, Supabase, PostgreSQL, OpenAI API.
